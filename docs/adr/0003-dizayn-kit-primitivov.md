# 0003. Дизайн всегда содержит кит примитивов

- **Статус:** заменён ADR-0004
- **Дата:** 2026-06-18
- **Связано:** `DESIGN.md`, `CLAUDE.md`,
  `.claude/skills/add-component/SKILL.md`, заменён [[0004-dizayn-sistema-sloi]],
  [[0002-design-md-kak-kontrakt-dizayna]]

> **Заменён [[0004-dizayn-sistema-sloi]]:** плоский кит `front/src/components/kit/`
> переработан в дизайн-систему `front/src/design-system/` со слоями
> primitives/patterns/layout. Контекст и мотивация «дизайн всегда несёт базовый набор»
> сохраняются; раскладка и термины — в ADR-0004.

## Контекст

После внедрения контракта `DESIGN.md` (ADR-0002) токены генерируются, но в шаблоне был
лишь один бизнес-компонент `ExampleCard.vue`. Не было базовых примитивов и правила, что
дизайн-система всегда несёт «дизайн-кит». Без этого каждый проект собирал бы кнопки,
инпуты и карточки заново, расходясь в стилях и дублируя токен-классы по компонентам.

## Решение

Шаблон всегда поставляет дизайн-кит примитивов — `front/src/components/kit/` (Button,
Input, Card, Badge, Checkbox, Select, Spinner) с реэкспортом через `kit/index.ts`.
Каждый примитив собран только на токенах из `DESIGN.md` и снабжён story-вариантами.
Правило (CLAUDE.md, DESIGN.md): дизайн всегда содержит кит; любой UI композится из
примитивов кита, а не из голых утилит/хардкода. Кит — реализация секции `components`
контракта в виде `.vue`. Бизнес-компоненты собираются из кита (`ExampleCard.vue`).

## Почему именно так

- **Один источник примитивов** на токенах против дублирования стилей по компонентам:
  смена токена в `DESIGN.md` меняет весь кит без правок `.vue`.
- **Нативные form-элементы** (Checkbox/Select/Input) вместо тяжёлых UI-библиотек —
  минимум кода и максимум доступности из коробки; стилизация — токен-утилитами.
- **Кит = реализация контракта**: секция `components` в `DESIGN.md` описывает примитивы
  токенами, кит даёт их `.vue`-воплощение — единая, проверяемая связь дизайна и кода.
- Story-варианты + addon-a11y дают визуальную и a11y-проверку каждого примитива.

## Последствия

Плюс: консистентный UI из коробки, новый проект стартует с готового кита, бизнес-UI
короче (композиция). Минус: `Button primary` наследует контраст-warning токена
`primary` (#3b82f6 на белом — 3.68:1, ниже WCAG AA) — advisory, правится затемнением
`colors.primary` в `DESIGN.md`. Нативные form-элементы ограничены в кастомной
стилизации — для шаблона достаточно.

## Где в коде

- `front/src/components/kit/` — примитивы и `index.ts` (помечен `ADR:`).
- `front/src/components/ExampleCard.vue` — образец композиции из кита.
- Скилл `/add-component` — процедура добавления примитива.
